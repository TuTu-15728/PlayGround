

## Pre-Engagement

### Lab Description

In this lab, you will exploit Textpattern CMS 4.8.3, which is vulnerable to Remote Code Execution (RCE), to gain an initial foothold. You will then escalate privileges by leveraging a Dirty COW kernel exploit to obtain root access.

### Learning Objectives

**After completion of this lab, learners will be able to:**
- Enumerate the target to identify services and accessible directories.
- Exploit the Textpattern CMS 4.8.3 to gain remote access.
- Upload and trigger a reverse shell to obtain an initial foothold.
- Enumerate the kernel version and prepare a Dirty COW exploit.
- Execute the kernel exploit to gain root access on the system.
